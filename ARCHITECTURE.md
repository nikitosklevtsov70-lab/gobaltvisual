# Архитектура Gobalt Visual

Этот документ описывает внутреннюю структуру мода **Gobalt Visual**, разделение ответственности между модулями и поток данных. 

Поскольку мод является **строго клиентским (Client-Side)**, вся его архитектура завязана на перехват (Mixin) и прослушивание (Events) клиентских событий без отправки пакетов на сервер.

## 📁 Структура проекта (Fabric Layout)

Проект использует стандартную структуру Fabric.

```text
gobaltvisual/
├── src/
│   ├── main/                  # Клиентский код (основная логика мода)
│   │   ├── java/.../gobaltvisual/
│   │   │   ├── GobaltVisualClient.java    # Главный Entrypoint (ClientModInitializer)
│   │   │   ├── config/                    # Система конфигурации
│   │   │   ├── event/                     # Обработчики событий (Tick, Render, Keybind)
│   │   │   ├── mixin/                     # Миксины (вмешательство в ванильный код)
│   │   │   ├── render/                    # Логика отрисовки (HUD и мир)
│   │   │   └── util/                      # Утилитарные классы (математика, хелперы)
│   │   └── resources/
│   │       ├── fabric.mod.json            # Манифест мода
│   │       ├── gobaltvisual.mixins.json   # Конфигурация миксинов
│   │       └── assets/                    # Текстуры, иконки, локализация (lang)
│   └── main/                       # (Обычно пусто, но требуется Fabric)
└── build.gradle                    # Настройки сборки и зависимости
