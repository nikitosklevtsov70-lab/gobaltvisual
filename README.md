# Gobalt Visual

**Gobalt Visual** — это клиентский мод для Minecraft (Fabric), ориентированный на PvP-визуал и Quality of Life (QoL) функции. Мод не даёт нечестного преимущества и создан для улучшения восприятия игры без вмешательства в игровой баланс.

![Version](https://img.shields.io/badge/version-2.0--a0-blue)
![Minecraft](https://img.shields.io/badge/minecraft-1.21.1-green)
![Fabric](https://img.shields.io/badge/loader-Fabric-orange)

##  Особенности

- **Кастомный рендер хитбоксов** — для более точного понимания попаданий.
- **Визуализация отбрасывания (Knockback)** — показывает вектор и силу отбрасывания противника после удара.
- **Кастомные шаблоны на броне** — клиентская косметика, позволяющая видеть выбранные узоры (тримы) без влияния на сервер.
- **Полная клиентская безопасность** — мод не отправляет на сервер никаких дополнительных пакетов, влияющих на геймплей.

##  Технические характеристики

- **Платформа:** Fabric
- **Версия Minecraft:** 1.21.1
- **Язык:** Java 21
- **Зависимости:** Fabric API, Yarn mappings

##  Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) для Minecraft 1.21.1.
2. Скачайте последнюю версию `gobaltvisual-x.x.x.jar` из раздела [Releases](https://github.com/nikitosklevtsov70-lab/gobaltvisual/releases).
3. Поместите `.jar` файл в папку `.minecraft/mods`.
4. Запустите игру с профилем Fabric.
